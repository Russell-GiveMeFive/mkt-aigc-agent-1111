L1基础素材

七类：底版图 / 花纹 / 艺术字字体样式 / 商品图 / 模特图(图·mp4) / 水印 / 标签样式
唯一 fileId（前缀=category），落 l1 桶

L2商品海报合成

样式合成：模板直出（默认「完整海报」模板）· parseAdjust 自然语言参数 · 秒出
AI 合成：选 L1 素材 + 自然语言 → M3 + load_skill 生成 720×1440 HTML（绝对定位）→ 违规文字清洗 / 底版强制垫底 → 无头 Chrome 截图 → PNG 落 l2 桶
生产管线标记（批量）决定能否进入 L3

L3海报合成 - 二次加工

① 管线生成：管线背景 + 商品(可选) + 模特(可选) + 文案槽位 → 严格版式合成 → QC 裁判 → 修复 ≤2 轮 → l3 桶
② 直通：不选商品/模特，L2 背景直接作为最终海报（source=direct）
③ 再加工：换商品图重新合成

L4视频合成

L3 海报 + motion-agent（M3 + load_skill 读 video scope 技能 → 运动提示词）→ H3 5s 竖版（ratio 3:4 / 分辨率 2K / 时长 4~15s 可调）
task 轮询（仅状态变化打日志）→ mp4 落 l4 桶
附：flat-safe 动效渲染端点（ffmpeg · 相框锁定规范）

引擎链路：copy（文案槽位直传 / M3 生成）→ bg（l2 桶 fileId 直读）→ compose（版式 v2 · 720×1440）→ qc（mock 启发式 / M3 视觉）→ video（mock ffmpeg / H3 v2 + 轮询）· 修复环路：缺陷码 → bg / compose / copy 阶段定向重跑 ≤2 轮 · trace 分组：L2 每单入口 newTrace 贯穿（解析→LLM 各轮→渲染→入库）；L4 以任务 id 为 traceId
