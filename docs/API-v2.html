素材工厂 v2 · 接口文档

双11 京东投流素材 AIGC · 三层素材模型开放接口 · 生成于 2026-03
Base URL　http://<host>:8788 鉴权　请求头 X-API-Key: <key>（设置页配置后启用；留空不鉴权） 格式　JSON（上传为 multipart/form-data） MOCK　未配置 MiniMax Key 时全链路本地模拟，协议与 LIVE 完全一致

四桶存储：l1 基础素材 / l2 平台合成素材 / l3 商家最终营销海报 / l4 视频合成。逐桶独立配置 local（本地磁盘）或 oss（S3 兼容对象存储）。所有桶内资源经统一代理访问：

GET /v2/files/{bucket}/{fileId}

fileId 规则：{category前缀}_{时间戳36进制}{6位hex}.{扩展名}（如 plate_mtymcg7xc1ae59.png），即唯一文件标识符，全链路引用。

分页查询：所有列表接口（L1/L2/L3/L4 的 assets 与 jobs）统一支持 ?page=1&pageSize=24（pageSize ≤ 200），统一出参 {items, total, page, pages, pageSize, hasMore}。列表读取本地素材库索引（SQLite：data/assets.db，各层素材统一入库，零 OSS 请求）；桶内容通过 POST /v2/buckets/:bucket/sync 对账补录（全量列举一次，OSS 自动循环翻页）。

GET/v2/files/:bucket/:fileId

读取任意桶内资源（图片 / 视频 / HTML 存档），带 1h 缓存头。

L1 基础素材

用户上传的原始素材，七类 category，fileId 前缀即 category。多文件一次上传即为批量。

POST/v2/l1/assetsmultipart
字段类型说明
categorytext必填：plate / pattern / arttext / product / model / watermark / labelstyle
files[]file一个或多个文件；图片，或 model 类的 mp4 视频
namestext可选，JSON 数组，与 files 对应的自定义名称
curl -X POST http://localhost:8788/v2/l1/assets \
  -F category=plate -F files=@底版.png -F files=@底版2.png

# 201
{ "items": [ { "fileId": "plate_mtymcg7xc1ae59.png",
    "url": "/v2/files/l1/plate_mtymcg7xc1ae59.png",
    "category": "plate", "name": "底版", "size": 12345, "createdAt": 1700000000000 } ],

列表，可按 category 过滤。

DELETE/v2/l1/assets/:fileId单个删除
POST/v2/l1/assets/delete批量删除

L2 平台合成素材

POST/v2/l2/compose-bg自然语言合成

选 L1 基础素材 + 一句自然语言 → LLM 生成 720×1440 HTML（绝对定位精细控制）→ 无头 Chrome 截图 → 存入 L2 桶（PNG + HTML 存档）。

{
  "itemIds": ["plate_x.png", "pattern_y.png"],
  "instruction": "底版铺满整张背景，金色粒子以 25% 透明度平铺，艺术字放上方居中",
  "name": "红金粒子 v2"
}

# 201（含生成的 HTML 全文，便于微调后重生成）
{ "fileId": "l2bg_mtymbsrac9a354.png", "url": "/v2/files/l2/l2bg_mtymbsrac9a354.png",
  "name": "红金粒子 v2", "htmlFileId": "l2bg_mtymbsrac9a354.html",
  "source": "minimax-m3+screenshot", "pipeline": false, "html": "<!DOCTYPE html>…" }

source 组成：{LLM 来源}+{渲染方式} —— minimax-m3 / mock-template + screenshot / fallback（无浏览器时 sharp 渐变兜底）。

POST/v2/l2/compose-bg/batch批量衍生
{ "jobs": [ { "itemIds": ["…"], "instruction": "…" }, { "itemIds": ["…"], "instruction": "…" } ] }
POST/v2/l2/pipeline生产管线标记（批量）

被标记的背景才有资格进入 L3 自动生成。

{ "fileIds": ["l2bg_x.png"], "enabled": true }
GET/v2/l2/assets?pipeline=1

列表；pipeline=1 只看管线内素材。

DELETE/v2/l2/assets/:fileId　POST/v2/l2/assets/delete

单个 / 批量删除（同 L1 模式）。

L3 商家最终营销海报

POST/v2/l3/generate管线生成 · 异步

bgFileId 必须是已加入生产管线的 L2 背景。合成（720×1440 京东版式）→ QC 裁判打分 → 缺陷自动修复（≤ maxRepairRounds 轮）→ 海报落 L3 桶。

{
  "bgFileId": "l2bg_x.png",            // 必填，L2 桶内且已标记生产管线
  "productFileId": "product_y.png",    // 必填，L1 商品图
  "modelFileId": "model_z.png",        // 可选，L1 模特图
  "modelVideoFileId": "model_v.mp4",   // 可选，L1 模特 mp4 → H3 Reference 模式
  "copySlots": {                       // 文案槽位直传，缺省自动生成
    "headline": "双11狂欢价\n好物到手",
    "productName": "限定礼盒", "price": "299", "oldPrice": "599",
    "cta": "立即抢购", "promo": "前2小时5折"
  },
  "generateVideo": false               // 完成后直接送 L4
}

# 202
{ "jobId": "tmtymcgak0j2m", "status": "running", "poll": "/v2/l3/jobs/tmtymcgak0j2m" }
POST/v2/l3/generate/batch批量衍生
{ "items": [ { "bgFileId": "…", "productFileId": "…", "copySlots": {} }, … ] }
POST/v2/l3/rework再加工 · 换商品图

对本系统生成的海报更换商品图重新合成（沿用原背景 / 模特 / 文案）。批量版 /v2/l3/rework/batch：{ "items": [ { "l3FileId": "…", "productFileId": "…" } ] }

{ "l3FileId": "l3_x.png", "productFileId": "product_new.png", "generateVideo": false }
GET/v2/l3/jobs?status=done　GET/v2/l3/jobs/:id

任务列表 / 详情。详情含 stages[]（copy→bg→compose→qc→video）、qc[]（verdict：pass / score / defects[] / repairPlan）、usable、qcScore、l3FileId、copy。

GET/v2/l3/assets

海报库：桶内容 + 关联任务的 QC 分 / 可用率 / 文案摘要。

DELETE/v2/l3/assets/:fileId　POST/v2/l3/assets/delete

单个 / 批量删除。

设置（含四桶配置）

GET/v2/settings　PUT/v2/settings

PUT 为增量合并。允许字段：apiKey / baseUrl / textModel / videoModel / videoResolution / qcModel / maxRepairRounds / concurrency / mock / apiKeys / buckets。

{
  "apiKey": "eyJ…", "baseUrl": "https://api.minimax.cn",
  "textModel": "MiniMax-M3", "videoModel": "MiniMax-H3", "qcModel": "MiniMax-M3",
  "maxRepairRounds": 2, "concurrency": 2, "mock": false,
  "apiKeys": ["my-client-key"],
  "buckets": {
    "l1": { "driver": "local" },
    "l2": { "driver": "oss", "endpoint": "https://oss-cn-beijing.aliyuncs.com",
            "bucket": "jd-l2", "accessKeyId": "AK", "secretAccessKey": "SK",
            "region": "oss-cn-beijing", "publicBaseUri": "https://cdn.example.com/l2" },
    "l3": { "driver": "local" },
    "l4": { "driver": "local" }
  }
}

每桶字段：driver(local|oss) / endpoint / bucket / accessKeyId / secretAccessKey / region / publicBaseUri / forcePathStyle。配置 publicBaseUri 后资源 URL 直接走 CDN 前缀。

POST/v2/buckets/:bucket/test连通性测试
{ "ok": true, "driver": "oss", "objects": 12 }
POST/v2/buckets/:bucket/sync桶内容对账

全量列举一次桶（OSS 循环翻页取全），把索引之外的对象补录进元数据（l1 按前缀推断 category）。列表接口零 OSS 请求，依赖此接口或正常读写流程维护的本地索引。

{ "ok": true, "objects": 12, "added": 3 }

技能（注入 pi Agent）

技能 = 上传的 Markdown 文档，注入 QC 裁判评审上下文（相当于给裁判装「平台规范手册」）；MOCK 模式不受影响。多文件一次上传即为批量。

POST/v2/skillsmultipart · .md/.txt
curl -X POST http://localhost:8788/v2/skills -F files=@京东双11海报设计规范.md

# 201 { "items": [ { "id": "skill_x.md", "name": "京东双11海报设计规范", "enabled": true, "size": 1024 } ] }
GET/v2/skills　POST/v2/skills/:id/enabled　DELETE/v2/skills/:id

列表 / 启停（{ "enabled": false }）/ 删除。

附：底层 MiniMax 调用（服务端出站）

M3 · Anthropic 兼容 Messages API
POST {base}/anthropic/v1/messages        # 鉴权 Authorization: Bearer <key>
{ "model": "MiniMax-M3", "system": "…", "messages": [...],
  "max_tokens": 32768, "thinking": { "type": "adaptive" } }
# 响应 content[] 内容块数组，取 type=text 拼接；thinking 块自动过滤
# 用途：文案 JSON（disabled）/ L2 HTML 生成（adaptive）/ QC 视觉（base64 image 块）
H3 · 视频 v2
POST {base}/v2/video_generation          # content 数组：text 必填 + 图片/视频参考
  # I2VA 首帧： { type:"image_url", image_url:{url}, role:"first_frame" }
  # R2VA 参考： { role:"reference_video" } / { role:"reference_image" }（与首尾帧互斥）
  # resolution(768P|2K) 与 duration(4~15s) 必填
→ { "task_id": "…" }
GET  {base}/v2/query/video_generation/{task_id}
→ { "task": { "status": "queued|running|succeeded|failed|cancelled",
              "content": { "url": "https://…mp4" }, "error": { "code", "message" } } }
image-01 · 生图（AIGC 背景备用）
POST {base}/v1/image_generation          # response_format: base64 → Buffer[]
